# 0. Твоя задача

В текущем workspace уже существует реализованный проект:

```text
Proof of Simulation
```

Он уже был:

* написан;

# 2. Не доверяй Completion Report

Считай Completion Report **заявлением, которое нужно проверить**, а не источником истины.

```text

```

Если отчёт говорит:

```text

```

самостоятельно перепроверь.

Если говорит:

```text
"Benchmark holdout: 100%"
```

проверь, что holdout действительно не использовался для настройки.

Если говорит:

```text
"null p = 1.0"
```

проверь:

* формулу;
* число null runs;
* число сравнений;
* что сравнивались именно maxima;
* что observed score определён корректно;
* что null budget сопоставим с original search budget.

# 150. Финальное правило проекта

Если после всех исправлений V2 показывает:

```text
prime-specific uplift ≈ 0
```

это хороший результат.

Если:

```text
prime-specific uplift > 0
```

но исчезает в matched controls:

это хороший результат.

Если:

```text
prime-specific uplift > 0
```

и переживает matched controls:

это очень интересный результат.

Если вместе с ним появляется:

```text
temporal prime response
```

и:

```text
search-aware null separation
```

и:

```text
depth/resolution stability
```

это уже серьёзная вычислительная аномалия в рамках данной математической системы.

Ни один из этих исходов сам по себе не доказывает, что физическая Вселенная является симуляцией.
