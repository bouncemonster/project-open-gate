# Proof of Simulation V2 — Preregistered Arithmetic Isolation

This protocol is fixed before any V2 search results. Machine-readable parameters and source/build hashes will be locked in `protocol_v2.json` and `reproducibility_v2.json` before the experiment. Audit probes are V1 diagnostics only. V1 files and results remain preserved; V2 uses `history_v2.sqlite3`, distinct run IDs, `kernel_v2.exe`, and suffixed artifacts.

## Models and numerical conventions

- Experiment identity V2_CORRECTED / V2_ARITHMETIC_ISOLATION; expanded-domain model V2_EXPANDED_DOMAIN. Main domain is [-2,2]² because the V1 optimum was within 5% of its real upper bound. No further result-driven expansion beyond this preregistered domain; a V2 boundary optimum is explicitly unresolved.
- Main dynamics: z(k)=z(k-1)^2+c+alpha*D(k), real forcing, alpha=1, k starts at 1; z(0) covers [-1.8,1.8]×[-1,1]. Endpoint-inclusive coordinates px/(width-1), py/(height-1). Escape after update at |z|²>4. Smooth escape is clamp(k-log(log|z|)/log(degree),0,N)/N. Discrete escape is k/N, with nonescaping pixels 1. Degree 2 primary; degree 3 diagnostic only.
- Dimensions default 60×30, bounded 2..512; iterations 1..20,000. Reject unknown/nonfinite/malformed inputs, unsupported models, and duplicate batch IDs. No silent fallback or depth clipping.
- Standard pi(0)=pi(1)=0; P(k)=1/max(pi(k),1), P(0)=1. E(k)=P(k)-P(k-1). Consequently prime 2 is an indicator event but has zero amplitude; nonzero forcing events start at 3. Store indicator-event and nonzero-event counts separately.
- V0..V8 retain documented legacy meanings except safety/Nyquist/channel fixes. Canonical driver names and explicit short aliases map one-to-one; unknown names fail. V7 always uses the imaginary channel.
- V9_PRIME_EVENT=E. S1_ANALYTIC=1/max(1,li(k)-li(2)+1), with k<=2 protected. li(x)=Ei(log(x)); use convergent series gamma+log(log(x))+sum(log(x)^m/(m*m!)) for x>=2, with explicit convergence bound. This is an approximation, not exact prime counting.
- S2_DATA_SMOOTHED uses a centered uniform moving average of P with window 5; sensitivity windows 3,5,9. Lower boundary clamps k to 1; future P values are generated, not truncated at requested depth.
- V10_PRIME_RESIDUAL is standardized P-S1. Centering/scaling uses the fixed first 200 elements for all depths; zero variance gives all zeros. V3/V4 and legacy smooth matching also use the fixed first-200 reference statistics, ensuring primary prefixes do not change with depth. Record raw and applied mean/std/min/max/RMS, matching transformations, and horizon.
- V11_MATCHED_EVENT permutes nonzero event amplitudes into distinct uniformly sampled positions over the requested finite window; seeds 101,202,303,404,505. V12_SHIFTED_EVENT circularly shifts the exact E window by 1,2,3,5,7,11,13,17,19,23. V13_GAP_MATCHED permutes the circular event gaps using those five seeds and a deterministic starting phase, preserving count, amplitudes and circular gap multiset. Finite-window controls are reconstructed per requested depth; they are not claimed to have depth-invariant prefixes. No selection of the best seed/shift.

## Targets and score

The C target-field generator is the only formula implementation; Python `target_field(target_id,width,height)` reads its numerical output. TARGET_A=abs(sin(pi*u)*cos(pi*v)); TARGET_B=sin²(pi*u)*cos²(pi*v); TARGET_PHASE uses wrapped (u+0.07,v-0.11). T_nm=sin²(n*pi*u)*sin²(m*pi*v), n,m=1..4: all 16 eigenmode holdouts. LOW_MODE_1..4 are fixed smooth separable fields defined in the generator, never optimized. Target A alone drives primary optimization.

Keep V1 metric weights (0.25 Pearson01, 0.15 each Spearman01, MAE01, Gradient01, Spectral01, Autocorrelation01), all clamped to [0,1]. Correlation of degenerate fields is neutral 0.5. Spectral search metric uses the existing signed 8×8 low-DCT coefficient cosine, excluding DC; this is not spectral magnitude equivalence. Gradient uses coordinate-aware finite differences. Export full-precision buffers; render from the scoring buffer without trimming whitespace. Store component scores and raw/difference fields.

Validation uses separable orthonormal full DCT-II/inverse DCT. Ten sign-randomized TARGET_A surrogates retain DC, mean, variance and coefficient magnitudes (no clipping or renormalization, which would destroy matching). Seeds 1001..1010. These fields may exceed [0,1]; MAE01 remains clipped. Record dominant frequencies, low/high non-DC energy (low=indices <8), and concentration. Never compute full DCT for every search candidate.

## Search and randomization

All scientific randomness uses SplitMix64 with stored named seed and checkpoint state. No clock/system randomness. Unique run IDs derive from experiment, role, track, and seed.

- Tracks A=V1, B=V10, C=V9, each separately stored, priority C/B/A.
- Each independent run: 17×17 coarse scout (289 evaluations), followed by exactly 100 steps ×9 candidates=900 evaluations. Total 1,189 per run including scout. Five deterministic basin starts are the top five distinct scout points, with stable candidate-ID tie breaks; each receives 20 steps. Include V0/V4 standalone scouts (289 each) without full control explosion.
- At each step evaluate eight compass neighbors and one uniform-domain mutation. Reflection at domain boundaries, not clipping; record duplicate parameter attempts explicitly. No data-dependent early stop. Step starts at 0.02 per basin, grows ×1.15 on strict improvement up to 0.2, otherwise halves down to 1e-5. Best changes only on strict score improvement; ties use first candidate. Every attempted candidate has a unique (run_id,step,candidate_id) key and persisted status.
- Three independent search seeds per track: 133742,233742,333742. All are reported; primary null comparison uses the preregistered first seed, not the best of three. The best across repeats is descriptive and receives validation, with selection caveat.
- Random-parameter-search control: same 1,189 evaluations, same domain/model/target per track and each of the three seeds, no hill climbing.
- Search-aware target-organization null: V9 and V10, eight independent null runs each, same 1,189 budget, domain, scout, five-start/restart/step rules, seed 133742 and model family as the first-seed primary. Only target changes to DCT sign surrogates 1001..1008. This isolates target organization, not prime order. Report plus-one empirical_search_null=(1+exceedances)/(1+8), not a calibrated physical p-value. Minimum attainable estimate is 1/9. Extended mode may preregister 12 before running; this execution uses eight.
- Report null mean/std/median/max, differences to observed, percentile, maxima/evaluation references, exact candidate budgets and algorithm. Matched event/shift contrasts independently test arithmetic timing.

## Validation and inference gates

At each selected track best, use identical c/alpha/degree/grid/depth for V0,V1,V2,V4,V5,V6,V8,V9,V10,S1,S2 and all V11/V12/V13 realizations. Store every member, not only aggregate winners. Primary contrasts: V1-V0; V1-max(S1,S2); V9-mean(V11); V9-mean(V12); V10-max(S1,S2). Also report V10-S1 as the requested residual_uplift, and shuffle degradation. Contrasts are not causal effects.

Validation: depths 200,500,1000,1500,2000; resolutions 60×30,120×60; alpha 0.25,0.5,1,2; local offsets (±0.001,0),(0,±0.001); TARGET_B, TARGET_PHASE, all 16 T_nm, four LOW_MODE targets, ten spectral targets. No reoptimization. Evaluate corresponding smooth and event controls at depth/resolution/holdouts to assess *contrast* stability, not just high absolute score. Stable absolute score means range<=0.05; positive contrast retention means >0.005 at every tested setting. A selected maximum at <5% of any boundary is flagged.

Temporal: one 5,000-step trace per selected candidate/driver (V1,V9,V10) and baseline at the same c. One-pass active-pixel statistics, iteration 1..5000. Exclude extinct/no-active samples; do not infer zero response from unobservable trajectories. Compare baseline-adjusted after-prime response against nearest unused non-prime iterations within ±10 and the same active-fraction bin. Detrend with fixed centered window 21. Report usable pair counts, mean paired contrast, standardized effect, bootstrap 95% interval and 1,000 sign permutations using seed 424242. Fewer than 20 pairs yields INSUFFICIENT_ACTIVE_DATA, not a positive or null signal. Prime indicator/gap/pi/inverse/residual fingerprints are analysis-only.

Benchmark: retain interpretable nearest-centroid features; exclude WORLD_PRIME entirely from training, feature scaling, thresholds and feature choice. Train seeds 1..10, validation 11..15, holdout 16..20. All WORLD_PRIME seeds 1..20 are holdout with deterministic distinct arithmetic-window/phase realizations and hashes. Adversarial compressed analytic, smooth+lattice artifact and quantized fractal worlds are holdout-only and labeled analytic-origin controls. Freeze existing features before reading benchmark results. Save every seed, split, feature, field hash, normalized feature, prediction, confusion matrix and precision/recall.

Status rules: NO_SIGNAL if primary similarity<0.6 and no meaningful positive contrasts; GENERIC_RESONANCE if similarity>=0.6 without consistent matched-control evidence; PRIME_CANDIDATE_SIGNAL if event and residual contrasts >0.005 at search settings; ROBUST_PRIME_SPECIFIC_SIGNAL additionally requires positive contrast retention at depths/resolutions/holdouts, positive temporal test (two-sided permutation<=0.05 with interval excluding zero), and separation above every fair null maximum. With only eight nulls, strength is exploratory and multiplicity remains a limitation. Missing required evidence yields UNRESOLVED; no automatic physical-simulation claim. Computational fingerprints are a separate exploratory output, not a combined simulation_score.

V2 runs persist protocol/source/binary hashes. Refuse incompatible resume. A transaction stores step evaluations and next controller+PRNG state together. On process timeout kill/reap the child, record failed attempt/event, leave the last committed checkpoint recoverable. Every major phase requires integrity_check='ok' and no foreign-key errors. CSV uses csv module quoting. Reports use run-filtered SQL and include evaluation references; primary/control/other/failed/total counts are explicit. Performance samples measure process/batch/database/render/analysis costs with the environment unchanged. Compact context is <=120 lines; no full evaluation history injection.
